## Project overview

Personal portfolio site for John Fulkerson (johnfulkerson.com), built with TanStack Start (React) and deployed as a Cloudflare Worker.

## Commands

Package manager is `pnpm` (a `pnpm-lock.yaml` is committed — don't use npm/yarn).

```bash
pnpm install       # install deps
pnpm dev           # start dev server on port 3000 (vite dev)
pnpm build         # production build (vite build)
pnpm serve         # preview a production build (vite preview)
pnpm test          # run the vitest suite once
pnpm lint          # eslint
pnpm format        # prettier (check only)
pnpm check         # prettier --write . && eslint --fix
pnpm deploy        # build, then `wrangler deploy`
```

To run a single test file with vitest: `pnpm vitest run path/to/file.test.ts`. There are currently no test files in the repo, but the vitest/jsdom/testing-library toolchain is installed and configured.

## Architecture

- **Framework**: TanStack Start (`@tanstack/react-start`) with file-based routing via TanStack Router. Routes live in `src/routes/`; adding a `.tsx` file there automatically registers a route — `src/routeTree.gen.ts` is generated by the TanStack Router Vite plugin and should not be hand-edited.
- **Root layout**: `src/routes/__root.tsx` defines the HTML shell (`RootDocument`), global `<head>` metadata, and renders `Header` on every route. Dev-only tooling (`TanStackDevtools`, router devtools panel) is gated on `import.meta.env.DEV`.
- **Router instance**: `src/router.tsx` (`getRouter`) — plain `createRouter` with `scrollRestoration: true` and `defaultPreloadStaleTime: 0`.
- **Deployment target**: Cloudflare Workers, configured via `wrangler.json`. The Worker entry is `@tanstack/react-start/server-entry`; static assets are served from `public/` via the `ASSETS` binding. The custom domain route (`johnfulkerson.com`) is bound in `wrangler.json` — don't change it without confirming with the user, since it affects live DNS/routing.
- **Build tooling**: Vite (`vite.config.ts`) composes the `cloudflare` plugin (SSR environment), `vite-tsconfig-paths` (enables the `@/*` → `./src/*` alias from `tsconfig.json`), Tailwind v4 (`@tailwindcss/vite`), `tanstackStart()`, and `@vitejs/plugin-react`.
- **Styling/UI**: Tailwind CSS v4, global styles in `src/styles.css`. Component styling follows shadcn/ui conventions (`components.json`: "new-york" style, zinc base color, `lucide-react` icons) — add new shadcn components with `pnpx shadcn@latest add <component>`, which will resolve into `src/components/ui` per the aliases in `components.json`. Page/section animations use `framer-motion`.
- **Static assets**: PDFs, images, icons, and sounds live under `public/` (e.g. `public/documents/Fulkerson_John_Resume.pdf`, `public/images/headshot.png`) and are referenced with root-relative paths in JSX.
- **Path alias**: import app code via `@/...` (e.g. `@/components/SocialIcons`) rather than relative paths, per the `@/*` alias in `tsconfig.json` and `components.json`.

## Conventions

- ESLint config is TanStack's shared config (`@tanstack/eslint-config`) — don't hand-roll custom rules in `eslint.config.js`.
- Prettier formats the whole repo (`pnpm format`) except entries in `.prettierignore`.
